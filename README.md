Este repositório contém o código do robô, equipado com um sistema de movimentação Swerve Drive, elevador de três níveis e uma garra articulada com diferentes posições para coleta de game pieces.

O projeto reúne a integração dos mecanismos, controle de movimentação e automação das funcionalidades do robô.

⚙️ Sistemas do Robô

 Drivetrain – Swerve Drive

O robô utiliza um sistema de movimentação Swerve Drive, permitindo movimentação omnidirecional, controle independente dos módulos e maior liberdade de movimentação durante o jogo.

🧭 Controle de direção e orientação do robô.

🏗️  Elevator – Elevador de 3 Níveis

O sistema de elevador foi desenvolvido para alcançar três níveis de altura

Nível

Altura

🟢 L1

9,5 cm

🔵 L2

52 cm

🟣 L3

72 cm

O mecanismo permite movimentação entre os níveis predefinidos, auxiliando no posicionamento e na execução das ações do robô.

Gripper – Garra Articulada

A garra possui três posições angulares distintas, permitindo adaptar sua orientação de acordo com a altura e a posição do game piece a ser coletado.

⬇️ Posição Inferior: Orientação voltada para coleta de game pieces diretamente do chão.

➖ Posição Intermediária: Garra posicionada horizontalmente, com orientação reta.

⬆️ Posição Superior: Garra inclinada para cima, permitindo coleta de game pieces em posições mais elevadas.

🧰 Tecnologias e Desenvolvimento

☕ Java – Linguagem utilizada no desenvolvimento do código.

🏎️ WPILib – Framework utilizado no desenvolvimento de projetos FRC.

🔄 Swerve Drive – Sistema de movimentação omnidirecional.
